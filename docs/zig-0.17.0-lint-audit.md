# Zig 0.17.0 audit of existing lints

This audit covers all **190 rule IDs present on `origin/main` before the 0.17
update**. Every ID appears exactly once in the table below. The four new opt-in migration
IDs are `modernize-deprecated-builtin`, `modernize-removed-syntax`,
`modernize-build-api` and `modernize-bitcast`; they are documented separately in
the [rule reference](../src/rules/RULES.md).
No existing rule is removed: the language, lifetime and policy checks remain
useful, while release-dependent API advice and ownership recognition are updated.

The review compares each rule's documented predicate, source matchers and emitted
API names with the official release notes and the downloaded 0.17.0 standard
library. “Retain” describes release relevance; it does not mean every possible
input program is proved correct by that lint.

One existing proof limitation surfaced in the incremental worker:
`incomplete-owned-field-cleanup` can select a nested container's `deinit` when
reviewing its enclosing container. The worker's queued URI field carries a
local suppression explaining its actual post-join cleanup; lifecycle tests
verify ownership and diagnostics freshness.

## Changes requiring existing-rule updates

- `@hasDecl` now exposes public declarations only, even in the same source file.
  The reflection lint distinguishes it from `@field` and `@hasField`.
- Array-list last-element fixes use `last().?`. Search fixes use current
  `find*` names and also recognize legacy spellings in migration input.
- Allocator printing creates owned slices, so lifetime checks and summaries
  recognize `print` and `printSentinel`. Writer printing remains a borrowing
  operation. Sentinel duplication uses `dupeSentinel(T, bytes, sentinel)`;
  removed `dupeZ` is never emitted by a current fix. Literal format checks decode
  string escapes and leave escaped format braces unchanged.
- Overlapping copy advice uses `@memmove`. NaN comparison messages do not claim
  floating-point equality is reflexive and do not suggest an unavailable builtin.
- Power simplifications match `pow` for explicit `f32` / `f64` types and preserve
  type coercion. They exclude integer `pow` and fallible `powi`, and do not remove
  calls from zero-exponent operands. Square-root actions for unknown or
  nonpositive operands require explicit selection because `pow` and `sqrt`
  differ on negative zero.
- Legacy `@cImport` migration inputs still receive duplicate-import diagnostics;
  the linter does not suggest the removed builtin for new 0.17 programs.

## Evidence

Release-note references:

- **R1:** [Public-only `@hasDecl`](https://ziglang.org/download/0.17.0/release-notes.html#codehasDeclcode-Returns-codetruecode-Only-for-Public-Declarations).
- **R2:** [ArrayList last-element API](https://ziglang.org/download/0.17.0/release-notes.html#ArrayList).
- **R3:** [Float equality and `mem.findDiff`](https://ziglang.org/download/0.17.0/release-notes.html#Handle-Floats-Correctly-in-codememeqlcode-and-codememfindDiffcode).
- **R4:** [Standard library changes](https://ziglang.org/download/0.17.0/release-notes.html#Standard-Library).
- **R5:** [`@cImport` removal](https://ziglang.org/download/0.17.0/release-notes.html#C-Translation-Moving-to-External-Package).
- **R6:** [Language changes](https://ziglang.org/download/0.17.0/release-notes.html#Language-Changes), including `@backingInt` / `@fromBackingInt`, array multiplication removal, `@bitCast`, `void{}` removal and `errdefer` capture removal.

Standard-library references are paths inside the official
[0.17.0 toolchain](https://ziglang.org/download/#release-0.17.0):

- **S1:** `lib/std/mem.zig`: current `find*`, `startsWith`, `endsWith`, scalar
  count/replace, split, equality and `@memmove` helper deprecations.
- **S2:** `lib/std/mem/Allocator.zig`: `print`, `printSentinel`, `dupeSentinel`,
  `free` and `destroy`; `lib/std/fmt.zig`: deprecated printing wrappers.
  Both printing sentinel APIs put the sentinel last.
- **S3:** `lib/std/array_list.zig`, `hash_map.zig`, `array_hash_map.zig` and
  `bit_set.zig`: container cleanup, optional pop/last and invalidation contracts.
- **S4:** `lib/std/math.zig`, `math/pow.zig`, `math/powi.zig`, `math/sqrt.zig`, `simd.zig` and
  `zig/BuiltinFn.zig`: NaN, fallible integer power, square root, iota and vector
  builtin availability.
- **S5:** `lib/std/Io/Reader.zig`, `Io/Writer.zig`, `Io/Dir.zig`, `Io/File.zig`,
  `process/Child.zig` and `Io.zig`: I/O interface lifetime, partial counts,
  directory iteration, process cleanup and synchronization.
- **S6:** `lib/std/fs/path.zig`: allocating path helpers; `Io.Dir.path` aliases
  this namespace. `zon/parse.zig` now allocates results from its supplied arena;
  the existing ownership catalog contains no stale ZON `free` summary.
- **S7:** `lib/std/testing.zig`: equality, string/slice equality, expected-error
  and approximate-equality assertions.

## Verification

Targeted regressions run with the official 0.17.0 compiler cover public/private
reflection, current and legacy search names, last-element fixes, printing
ownership and wrapper provenance, writer-print exclusion, final sentinel
arguments, escaped format braces, sentinel duplication, arena reset invalidation,
power type coercion, preserved operand evaluation and signed-zero behavior.
A compiled 0.17 API probe also exercises `last().?`, `findScalar`,
`findScalarLast`, `dupeSentinel`, `printSentinel`, `@memmove`, `sqrt`, `isNan`
and `simd.iota`. The repository's host checks and full test workflow provide the
broader parser, rule, example and compiler integration coverage.
